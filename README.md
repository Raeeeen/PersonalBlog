# PersonalBlog

PersonalBlog is a personal blog website I developed as a **school project to document my internship at EdFolio**, where I worked as a Web Developer.

As part of our school requirements, we were asked to create a blog documenting our internship experience, including the tasks we worked on, projects we contributed to.

I used this website to keep a record of my tasks during my time at EdFolio. It also helped me practice and improve my web development skills while documenting my internship.

## Project Purpose

The website was created as part of a **school requirement for our internship/OJT**. Its purpose was to document and share our experiences and work throughout the internship period.
